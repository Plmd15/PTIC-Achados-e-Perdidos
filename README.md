Achados e Perdidos

📌 Sobre o Projeto

O Achados e Perdidos é um sistema digital projetado para organizar, centralizar e agilizar o processo de registro, consulta, localização e devolução de objetos perdidos em ambientes de grande circulação (como a Etec Cidade Tiradentes).

O sistema substitui o controle manual por uma solução digital integrada (Web e Mobile), reduzindo o acúmulo de objetos e aumentando a taxa de devolução aos seus donos.

🚀 Tecnologias e Recursos

Plataformas: 
Web (responsivo) e Mobile


Consulta: 
Catálogo digital em tempo real

Acesso Rápido: Leitura de QR Code espalhados pela instituição para acesso direto ao catálogo

Controle de Versão: Git e GitHub

🔐 Segurança e Acesso
Autenticação de usuários (login/senha)

Controle de acesso baseado em perfis (Usuário comum, Funcionário, Gerente)

Validação presencial e confirmação de dados para devolução

Histórico e trilha de auditoria para entradas e saídas de itens

✨ Principais Funcionalidades
Consultar Catálogo (Busca de Objetos):

Pesquisa por texto (nome do objeto)

Filtros avançados por categoria, cor, data e local onde foi encontrado

Cadastrar Objetos Encontrados:

Registro do item com foto, nome, categoria, cor, data, hora e local onde foi achado

Solicitar Retirada & Dar Baixa (Saída):

O dono do objeto faz uma solicitação de retirada pelo sistema

O funcionário valida as informações no balcão e registra a devolução (alterando o status do item para Devolvido)

Gestão e Relatórios:

Gerenciamento de acessos de funcionários

Geração de relatórios gerenciais e estatísticas de itens por período

🔄 Fluxo Operacional do Sistema
Entrega: Um objeto encontrado é entregue no balcão de atendimento.

Registro: O funcionário cadastra o objeto e suas características no sistema.

Disponibilização: O item fica visível no catálogo público (via Web ou escaneando o QR Code).

Solicitação: O dono localiza o item no catálogo e solicita a devolução pelo sistema.

Validação: No balcão, o atendente confere os dados do solicitante.

Conclusão: O item é entregue e o status é atualizado para Devolvido.

👥 Perfis de Usuários
Perdedor / Achador (Usuário Público/Externo): Consulta o catálogo para buscar itens perdidos ou entrega objetos encontrados.

Funcionário (Interno): Realiza o cadastramento de novos objetos, atende os usuários e registra as saídas/devoluções.

Gerente (Administrador): Cadastra/remove funcionários, visualiza relatórios e gerencia as configurações gerais do sistema.
